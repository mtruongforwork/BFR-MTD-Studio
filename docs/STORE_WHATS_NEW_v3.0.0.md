# What's new v3.0.0 (<= 1500 ký tự mỗi ngôn ngữ)

## en-US

BFR 3.0 is now "BFR — File & Document Hub": a 100% offline all-in-one suite for PDF, Office docs, OCR, images, and batch renaming.

CONTEXT-AWARE 2-RING RADIAL MENU
- Trigger from anywhere via hotkey or non-blocking Middle-Mouse Hold (220ms)
- Automatically detects active files in Explorer, Word/Excel/PowerPoint, or local PDFs in Edge/Chrome/Reader
- 8 dynamic wedges + Outer Sub-Arc presets adapt to PDF, Office, Images, Text/CSV, or mixed files
- Actionable Glass Toast with live progress, size savings, Open, Undo, and Continue With chaining

NEW PDF STUDIO (100% OFFLINE)
- Virtualized thumbnail grid (64 MB RAM cap) for 1,000+ page PDFs with drag-and-drop reorder, rotate, delete, and Scissor Split
- Merge PDFs & mixed files, compress (3 levels), Images <-> PDF, Markdown/TXT/CSV -> PDF, AES Protect/Unlock, Watermark, Page Numbers, and Repair/Flatten

NEW DOCS & OCR STUDIO (100% OFFLINE)
- Offline OCR (en, vi, fr, zh-Hans) via Windows OCR with Split-View editor and Searchable PDF export
- Hybrid DOCX/XLSX/PPTX -> PDF conversion, Office Privacy Cleaner (strip authors, comments, revisions), XLSX <-> CSV/JSON, and PDF -> Text/MD/DOCX

SMART HUB & AUTOMATION
- Smart Home dropzone, All Tools filter tabs & Favorites, Continue With tool chaining, plus PDF/Docs steps in Workflows, Watch Folders, and bfr CLI

Existing lifetime Pro users unlock ALL v3.0 Pro features at no extra cost.
