# What's new v2.0.0 (<= 1500 ký tự mỗi ngôn ngữ)

## en-US (909 ký tự)

BFR 2.0 turns the renamer into a batch file toolkit.

NEW TOOLS (preview, confirm, apply, undo)
- Organize into folders
- Find duplicates (extra copies go to quarantine)
- Folder tools: flatten, clean empty folders
- Dates, attributes and GPS (remove GPS from JPEG without re-encoding)
- Image tools: convert, resize, auto-rotate, compress
- ZIP compress and extract, safe against zip bombs
- Checksum: MD5, SHA-1, SHA-256
- Analyze a folder with a size map
- Workflow (Pro): chain steps, undo all at once

NEW LOOK
- New home page, light and dark themes, 3 accent palettes
- Radial tools menu at the cursor (optional hotkey)
- Explorer right-click: Organize, Duplicates, Dates/GPS, ZIP, Checksum

SAFER
- "Delete" moves files to a quarantine kept 30+ days
- System folders are never touched
- Fix: undoing a case-only rename

Pro is now 7.99 USD for new buyers. Existing Pro owners keep Pro at no extra cost.
